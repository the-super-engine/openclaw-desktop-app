# OpenClaw Desktop

开放龙虾宝-桌面版 - 面向中国大陆用户的 OpenClaw AI 智能体图形界面。

## 特性

- **默认 Minimax**，**推荐 DeepSeek**
- **飞书、钉钉** 优先配置
- 中英双语，白蓝/黑蓝主题
- 完整功能：Chat、Channels、Skills、Cron、Settings

## 开发

```bash
pnpm install
pnpm run dev
```

## 打包

```bash
pnpm run package        # 当前平台
pnpm run package:win    # Windows
pnpm run package:mac    # macOS
pnpm run package:linux  # Linux
```
