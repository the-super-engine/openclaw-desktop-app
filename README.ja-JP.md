# OpenClaw Desktop

中国大陸ユーザー向けの OpenClaw AI エージェントグラフィカルインターフェース。

## 機能

- **デフォルト Minimax**、**推奨 DeepSeek**
- **飛書・釘釘** 優先設定
- 日中英多言語、白青/黒青テーマ
- Chat、Channels、Skills、Cron、Settings の完全機能

## 開発

```bash
pnpm install
pnpm run dev
```

## パッケージ

```bash
pnpm run package
pnpm run package:mac
pnpm run package:win
pnpm run package:linux
```
